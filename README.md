Blog Post Application

A simple blog post app built with HTML, CSS, and vanilla JavaScript. 

Features
* Add a blog post (title and content)
* Edit a blog post (both title and content, each with its own success message)
* Delete a blog post (with a confirmation and a success message)
* Starts with three sample posts
* Cancelling or leaving a prompt empty does not create or change a post. 

Files
* index.html: page structure
* style.css: styling
* script.js: add, edit, and delete logic

How to run

Download the files into one folder and open index.html in a browser.
